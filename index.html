ANSI V1
প্রস্তুত। কনভার্ট করতে একটি বাটনে ক্লিক করুন।
ম্যাপিং ফাইল পরে যোগ করবেন:

এই প্রজেক্টে ANSI V1, V2 ও V3-এর জন্য আলাদা JavaScript ফাইলের জায়গা রাখা হয়েছে। আসল converter/mapping code না দেওয়া পর্যন্ত রূপান্তর বাটন placeholder হিসেবে থাকবে।

  • converters/ansi-v1.js — এখানে ANSI V1-এর আসল কোড যোগ করুন।
  • converters/ansi-v2.js — এখানে ANSI V2-এর আসল কোড যোগ করুন।
  • converters/ansi-v3.js — এখানে ANSI V3-এর আসল কোড যোগ করুন।

কোড যোগ করার পর app.js-এ দেখানো নির্দেশনা অনুযায়ী সংশ্লিষ্ট converter function যুক্ত করতে হবে। শুধু ফাইলের নাম রাখলে নিজে থেকে conversion চালু হবে না।
